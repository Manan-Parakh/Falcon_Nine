# 🚀 Falcon Nine: SpaceX Falcon 9 Launch Analysis

A comprehensive data science project analyzing SpaceX's Falcon 9 launches, focusing on predicting the success of the first stage landing using data collection, exploratory analysis, machine learning, and interactive visualization.

## 📚 Project Overview

This project explores SpaceX Falcon 9 launch data to understand and predict landing success. It covers data collection (via APIs and web scraping), data cleaning, exploratory data analysis, model building, and deployment of an interactive dashboard.

## 🧰 Technologies Used

- Python (Jupyter Notebooks)
- Web Scraping (BeautifulSoup)
- Data Wrangling (Pandas, NumPy)
- Exploratory Data Analysis (Matplotlib, Seaborn, SQL)
- Machine Learning (Scikit-learn)
- Visualization (Folium, Plotly Dash)
- Deployment (Streamlit)
  
### Usage

Open and run the notebooks in order:

1. Data Collection (APIs and Web Scraping)
2. Data Wrangling & Cleaning
3. Exploratory Data Analysis
4. Machine Learning Model Development
5. Visualization with Folium
6. Deployment using Streamlit (`spacex_dash_app.py`)

## 📈 Key Insights

* Developed models to predict Falcon 9 first stage landing success.
* Created interactive visualizations and maps to analyze launch data.
* Extracted valuable insights on factors influencing landing outcomes.
